# Student Marks Analyser

A simple python project that calculate student marks, average, grade and pass/fail status.

## Features 

- Accepts students name
- Accepts marks for five subjects
- Calculate Average marks
- Assigns a grade 
- Determine pass/fail status
- Saves student result to csv file

## Subjects
This project currently use:

- Python
- Database
- Maths
- English
- Computer

## Technologies used

- python
- csv
- Git
- Github

## How to run

open the project in VS code.
open the terminal and run :
```bash
python main.py
```
